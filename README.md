# Traty Bot — учёт трат в Telegram

Личный бот: записывает траты, переводит их в **часы твоего времени**,
ведёт долги, каждый вечер напоминает, а в конце месяца присылает сводку.
Многопользовательский — у каждого свои траты и долги, чужого никто не видит.

## Что умеет

- **Записать трату** — просто пришли `1500 продукты` или `350 такси`.
  Бот запишет и сразу скажет, во сколько **часов работы** это тебе обошлось.
- **⏱ Калькулятор** — посчитать часы для любой суммы, ничего не записывая.
- **📌 Долги** — «я должен» и «мне должны», с датой возврата. Когда срок
  наступает — бот напоминает.
- **📊 Сводка** — сколько и на что ушло за месяц (разбивка по категориям,
  % от дохода, эквивалент в часах). Можно листать по месяцам и смотреть «сегодня».
- **⚙️ Настройки** — **месячный доход**, рабочие часы в месяц, валюта, время
  вечернего напоминания, вкл/выкл ежедневного напоминания.
- **Вечернее напоминание** — каждый день в заданное время просит прислать траты.
- **Месячная сводка** — в последний день месяца приходит автоматически.
- **Админ** — о каждом новом подключившемся приходит уведомление главному админу.
  Админ видит только список пользователей (имена и количество), но **не** их траты.

## Как считаются «часы твоего времени»

```
ставка за час = доход в месяц ÷ рабочие часы в месяц
часы для суммы = сумма ÷ ставка за час
```

По умолчанию: доход `100 000`, рабочих часов `160` (8 ч × 20 дней) → ставка
`625/ч`. То есть трата `5000` = `8 ч` твоего времени. И доход, и часы меняются
в **⚙️ Настройки** (кнопка «💰 Доход в месяц»).

## Управление

Всё кнопками — reply-меню снизу и inline-кнопки. Команды: `/start`, `/menu`,
`/cancel`, `/help`.

## Запуск локально

```bash
cd traty-bot
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env              # впиши BOT_TOKEN (уже вписан в .env)
python bot.py
```

Первый, кто нажмёт `/start`, автоматически станет **главным админом**
(если `ADMIN_ID` в `.env` не задан).

## Запуск на сервере (systemd)

```bash
sudo mkdir -p /opt/traty-bot && sudo cp -r . /opt/traty-bot/
cd /opt/traty-bot
python3 -m venv venv && ./venv/bin/pip install -r requirements.txt
sudo cp traty-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now traty-bot
journalctl -u traty-bot -f        # логи
```

## Безопасность данных

- **Токен** и **ключ шифрования** лежат только в `.env` — файл в `.gitignore`,
  на GitHub не попадает. В репозитории только `.env.example` с заглушками.
- **База зашифрована.** Суммы, категории, заметки и долги хранятся в `data.db`
  зашифрованными (Fernet: AES-128-CBC + HMAC), ключ — `DB_KEY` в `.env`.
  Даже если файл базы утечёт без ключа — прочитать траты нельзя.
- ⚠️ **Не теряй `DB_KEY`** — без него расшифровать базу невозможно. Сделай копию.
- Разные пользователи бота изолированы: каждый видит только свои траты и долги.

## Устройство

| Файл | Назначение |
|------|------------|
| `bot.py` | хендлеры aiogram 3, меню, планировщик напоминаний |
| `db.py` | SQLite: users / expenses / debts / meta, изоляция по `user_id` |
| `logic.py` | чистая логика: разбор сумм/дат, расчёт часов, форматирование |
| `_selftest.py` | юнит-тесты логики и БД (`python3 _selftest.py`) |

## Настройки по умолчанию

- Валюта: `₽` (меняется в настройках)
- Таймзона: `America/Sao_Paulo` (Рио) — по ней считаются день/месяц и время
  напоминаний. Можно поменять переменной окружения или в БД (`users.tz`).
- Вечернее напоминание: `21:00`.

Только бесплатные сервисы: Telegram Bot API + SQLite. Ничего платного.
