# Traty Bot — версия для Cloudflare Workers

Тот же бот учёта трат, но serverless: работает 24/7 в облаке Cloudflare,
**бесплатно, без карты**. Развёрнут и живёт на:

**https://traty-bot.strelnikov2302.workers.dev**

## Как устроено

- **Webhook** — Telegram шлёт апдейты POST'ом на воркер (не polling).
- **Хранилище — Cloudflare KV** (`user:*`, `exp:*`, `debt:*`, `meta:*`).
- **Шифрование** — суммы, категории, заметки, контрагенты шифруются через
  Web Crypto **AES-GCM**, ключ — секрет `DB_KEY`. В KV лежит только шифртекст.
- **Напоминания и месячная сводка** — Cron Trigger (`* * * * *`, каждую минуту),
  обработчик `scheduled()`.
- **Изоляция пользователей** — ключи KV содержат `user_id`, callback'и берут id
  из `from.id`. Один не видит данные другого.

Фичи те же, что в Python-версии (см. `../README.md`): учёт трат → часы времени,
калькулятор, долги с напоминанием, сводка, настройки дохода/часов/валюты/времени,
уведомление админу о новых пользователях.

## Секреты (в воркере, не в коде)

Заданы через `secret_text`-binding при деплое, хранятся в Cloudflare:
- `BOT_TOKEN` — токен бота
- `DB_KEY` — ключ шифрования (AES-256). **Не терять** — иначе данные не прочитать.
- `WEBHOOK_SECRET` — проверка заголовка вебхука

Локальная копия секретов + id ресурсов — в `cloudflare/.env` (в git не попадает).

## Тесты

```bash
node _test.mjs         # чистая логика (парсинг, часы, форматирование)
node _test_crypto.mjs  # шифрование AES-GCM (round-trip, шифртекст скрывает данные)
```

## Передеплой (после правок worker.js)

`wrangler` не нужен — деплой напрямую через API. Нужен Cloudflare API-токен
с правами Workers Scripts + KV:

```bash
CF_API_TOKEN=твой_cloudflare_api_token ./deploy.sh
```

Скрипт читает `KV_ID` и секреты из `cloudflare/.env` и заливает `worker.js`.
Токен `DB_KEY` при каждом деплое переиспользуется из `.env` — так данные
остаются читаемыми.

## Управление вебхуком

```bash
# посмотреть статус
curl "https://api.telegram.org/bot<TOKEN>/getWebhookInfo"
# снять вебхук (вернуться на polling / локальную версию)
curl "https://api.telegram.org/bot<TOKEN>/deleteWebhook"
```

> ⚠️ Бот не может одновременно работать на Cloudflare (webhook) и локально/на VPS
> (polling) — один токен = один «слушатель». При переключении снимай вебхук.
